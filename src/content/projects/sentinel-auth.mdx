## The Challenge
Most standard auth implementations trust the client too much. For this project, I assume the client environment is compromised.



## Architecture
I chose a **Stateless JWT** approach but hardened it with **Redis-backed Refresh Token Rotation**. If a token is reused, the entire family is invalidated immediately.

```typescript
// Explicit rotation logic
export async function rotateRefreshToken(token: string) {
  const isRevoked = await redis.get(`revoked:${token}`);
  if (isRevoked) {
    await revokeAllFamilyTokens(token); // Nuclear option on suspected theft
    throw new SecurityError("Replay attack detected");
  }
}
